# 💅 Система онлайн-записи для мастера маникюра

Синхронизированный веб-сайт и Telegram Mini App с уведомлениями мастеру в Telegram, прикреплением фото-референсов дизайна и удобным управлением расписанием прямо со смартфона.

---

## 🌸 Возможности системы

1. **Красивый эстетичный интерфейс**:
   - Оформлен в теплой оливково-льняной эстетике вашего прайс-листа.
   - Точные услуги и цены:
     - **Маникюр с покрытием:** 1 200 ₽
     - **Маникюр с покрытием + дизайн:** от 1 200 ₽
     - **Наращивание без дизайна:** 1 800 ₽
     - **Наращивание с дизайном:** от 1 800 ₽
2. **Мгновенная синхронизация 100%**:
   - Занятые слоты моментально блокируются, исключая двойную запись.
3. **Загрузка референсов дизайна**:
   - Клиент прямо с телефона может прикрепить фото желаемого дизайна.
4. **Уведомления мастеру в Telegram**:
   - В личные сообщения бота приходит карточка: Имя, телефон, ник в TG, услуга, дата, время, комментарий и **фотография референса**!
   - Кнопки быстрого действия: `[✅ Подтвердить]`, `[❌ Отклонить]`, `[💬 Написать клиенту]`.
5. **Кабинет мастера со смартфона**:
   - Управление окошками: можно в 1 тап открывать или закрывать свободные часы.

## 🚀 Быстрый запуск на компьютере (Локально)

1. Откройте папку проекта `nail-booking-app`.
2. Дважды кликните на файл `start.bat` (или выполните команду `py run.py` в терминале).
3. Откройте в браузере:
   - **Сайт онлайн-записи**: [http://localhost:8000](http://localhost:8000)
   - **Кабинет мастера (слоты)**: [http://localhost:8000/admin](http://localhost:8000/admin)

> [!NOTE]
> В локальном режиме (без указания токена бота) система работает в режиме симуляции: вы можете оформить тестовую запись и прикрепить любое фото, а данные и уведомление отобразятся в терминале.

## 🤖 Как подключить Telegram-бота (3 шага)

### Шаг 1. Создать бота в Telegram
1. Откройте бота **[@BotFather](https://t.me/BotFather)** в Telegram и отправьте команду `/newbot`.
2. Введите имя для вашего бота (например, `Маникюр Анна | Запись`).
3. Введите юзернейм для бота, заканчивающийся на `bot` (например, `anna_nails_booking_bot`).
4. Скопируйте полученный **HTTP API Token** (вида `7123456789:AAFxxx...`).

### Шаг 2. Узнать свой личный Telegram ID
1. Напишите боту **[@userinfobot](https://t.me/userinfobot)** в Telegram.
2. Он пришлет ваш числовой `Id` (например, `123456789`).

### Шаг 3. Вставить данные в файл `.env`
Откройте файл `.env` в папке проекта и заполните:
```env
BOT_TOKEN=ваш_токен_от_BotFather
MASTER_TELEGRAM_ID=ваш_числовой_id
```

## 🌐 Бесплатный деплой в интернет (Хостинг 0 ₽)

Чтобы бот и сайт работали 24/7 без включенного домашнего компьютера, проект готов для развертывания на бесплатных облачных платформах:

### Вариант: Render.com (100% бесплатно)
1. Зарегистрируйтесь на [render.com](https://render.com) (через GitHub или почту).
2. Нажмите **New +** -> **Web Service**.
3. Подключите репозиторий с проектом.
4. Укажите:
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
5. В разделе **Environment Variables** добавьте ваши `BOT_TOKEN` и `MASTER_TELEGRAM_ID`.
6. Вы получите бесплатный адрес вида `https://nail-booking.onrender.com`.

## 📢 Как привязать бота к вашему Telegram-каналу

1. В **[@BotFather](https://t.me/BotFather)** отправьте команду `/mybots` -> выберите вашего бота -> **Bot Settings** -> **Menu Button** -> **Configure menu button**.
2. Укажите ссылку на ваш сайт (например, `https://nail-booking.onrender.com`) и название кнопки: `💅 Записаться`.
3. В шапке (описании) вашего Telegram-канала разместите ссылку на бота:  
   `Запись онлайн в 1 клик 👉 @ваш_бот`.
4. В конце каждого поста с фотографией работ добавляйте кнопку или строчку:  
   `Свободные окошки и запись онлайн: @ваш_бот`.
